# Library
This program is designed for a user to add books to their library. The user is required to click the 'add book' button and enter their book's details. These details include title, author and amount of pages. Their book will be added into a 'card' on their dashboard and the user can choose to remove the book or click a button to change their read/unread state.

## Technology used
 - HTML/CSS
 - JavaScript

## Learning focus
The aim to to explore more of Javascript and learn how to make a site more interactive.
